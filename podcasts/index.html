物理规律发现播客

当前生成 8 期中文双人对谈脚本。每个 Markdown 文件可直接交给豆包的播客/音频生成功能，也可接入获得授权的中文 TTS。脚本保留主持人追问、数学解释、实验边界和来源范围，不把教学实验冒充作者复现。

使用方式

  1. 选择一期开头的 Markdown 脚本。
  2. 在豆包中打开播客/音频生成功能，把该脚本作为学习材料导入。
  3. 指定“中文、双人科研对谈、面向有线性代数基础但没系统学过方程发现的听众、约18分钟”。
  4. 生成后检查公式、论文标题、作者名，以及“作者代码复现”和“独立教学实现”是否被正确区分。
  5. 发现朗读错误时，回到对应学习卡和原文；不要让音频模型自行补写性能数字。
