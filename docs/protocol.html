每篇论文都可追溯的复现协议

代码来源与最终目标

public_verified：已核查作者关系，公开页面/仓库可访问。author_link：原文明示作者链接，但下载或归档入口未完全核实。candidate：候选仓库，尚不足以证明作者关系。unverified：当前检索未定位。unavailable：原文称待发布或按请求提供，只代表所查来源的声明，不证明今天一定不存在。

前三种都必须继续检查版本、许可证、数据和依赖。确认作者代码后最终目标均为T2；没有访问成功的记录不能说“已经下载”。现阶段仅核查元数据和运行说明，并未安装运行所有仓库。

T0：冻结实验合同

在论文学习页“登记复现证据”中填写下列字段；额外配置、数据划分和种子写入个人笔记或实验记录：

  • 论文版本、目标图表或实验段落；作者原文的具体值/结构。
  • 仓库、分支、commit；原论文发布版本与当前默认分支可能不同。PDE-Net 2.0尤其注意版本分支。
  • 解释器、操作系统、CUDA及关键依赖；数据来源与许可；下载与预处理版本。
  • 训练/验证/测试轨迹或场的完整划分，不随机切碎同一轨迹后冒充独立测试。
  • 指标、容差和种子，在运行前确定。结构比较允许经过说明的代数等价；随机算法以原文统计协议为优先，单种子不能代表均值。
  • 运行命令、预计CPU/GPU/内存/磁盘消耗、超时预算。

T1：运行最小样例

先使用作者推荐环境与原始入口。保存标准输出、错误日志、命令与实际配置；检查数据尺寸、单位和初值。T1只确认代码能跑，不意味着恢复了正确方程。

T2：复现核心结果

每篇至少一个支撑主结论的实验，恢复原文设置。报告：

方法类型 首要结果 独立核对
稀疏方程 正确项、漏项、伪项与系数 未见整条轨迹/初值
隐式方程 规范归一化后的关系 不把整体倍数差异计错
神经坐标 重建、动力学、坐标对应 等价坐标下比较而非直接比系数
守恒量 独立量数目、轨迹内变化 未见轨迹与守恒量重参数化
SDE/SPDE 漂移与扩散的约定和误差 稳态分布/相关时间/留出统计
符号搜索 正确表达式成功率 同评价次数、时间和种子预算
真实物理 作者核心预测和可复现实验图 未用于筛选的条件或批次

保留论文目标值、实际值、容差、结果路径和源配置。若结果不符，标明环境差异、数据不齐或算法差异，不悄悄更改预期。复现作者结果与证明作者结论正确是两回事。

T3：只改变一个因素

使用学习卡指定的改变，冻结其他参数。保存正结果与失败结果。没有候选库真值的现实数据不使用“真结构恢复率”；报告可观测预测和稳定性。

环境分组与计算队列

  1. 基础CPU：numpy/scipy、SINDy、弱积分与统计模型。
  2. PyTorch：DeepMoD、符号生成等；每个不兼容仓库单独环境。
  3. TensorFlow旧代码：保留作者版本或隔离容器；移植成新框架须作为单独实现登记。
  4. MATLAB / Julia / R：用原语言运行；MATLAB缺许可证时如实阻塞，不把Octave数值等同于原环境。

本课程不把48篇论文对应代码的依赖混装进现有科研环境。部分论文共用仓库。super-server 可以作为之后复现的执行环境，但课程交付没有启动付费作业或长训练。

每次远端运行结束，把源码commit、环境导出、配置、日志和指标同步到本地 runs/Pxx/；面板中填本地报告路径。不要只保留远端终端滚屏。

工具选择与入口

  • PDF/Zotero用于原文和补充材料；已有全文文本用于搜索定位。
  • 官方仓库README与锁定版本优先于非官方教程；代码审计记录实际提取的命令，没有入口则列为待定位。
  • Jupyter/JupyterLab适合逐单元理解作者notebook；命令行脚本适合保存日志和批量参数扫描。
  • Python标准库学习面板管理笔记、测验、日历和进度，零额外依赖。
  • Conda/venv用于环境隔离，git用于只读获取和版本定位；无需提交或推送GitHub。

官方参考入口：https://pysindy.readthedocs.io/ 、https://jupyterlab.readthedocs.io/ 、https://docs.conda.io/ 。论文特定依赖以本地核查的README为准。

失败时怎么推进

定位材料/环境问题最多使用一个45分钟调试块；记录精确错误并转入下一篇阅读，保留复现队列。数值失败先核对版本、数据、种子和精度，再考虑算法差异。连续两天同一阻塞未解时，由对话教练单独诊断；不能为赶进度把结果改成通过。
