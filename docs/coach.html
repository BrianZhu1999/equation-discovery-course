学习指引

输入“开始今天”“第几天”或“Pxx”后，先打开课程日历和对应学习卡，再根据学习者的笔记和答案推进推导。Pxx 沿用原综述编号，rank 表示课程顺序。

一次学习会话

  1. 先回答一个诊断问题，确定未知对象是系数、结构还是坐标。
  2. 根据回答选择数学补课模块，先解释术语再使用缩写。
  3. 沿学习卡给出的原文页码阅读关键转化；补充推导单独标明。
  4. 完成推导的第一步，再继续下一步和闭卷自测。
  5. 检查配置文件、源码版本、数据和目标图表，按原文设置记录运行结果。
  6. 固定其他设置，完成学习卡指定的单因素比较。
  7. 复述方法、假设和实验结果，安排 1、3、7、14、30 天复习。

自测分数

  • 0：重新阅读对象定义和关键步骤，次日复习。
  • 1：补齐推导或假设，3 天后复习。
  • 2：独立推导并解释实验，按间隔复习。

运行记录

T1 表示最小示例，T2 表示按论文设置运行一个核心案例，T3 表示一次受控改动。教学示例和作者代码运行分别记录。学习卡提供出版页面和代码入口。

会话指令

  • “开始今天”：定位课程日并先做主动回忆。
  • “这步我不懂”：用二维或标量例子解释每个量。
  • “检查我的推导”：逐行检查假设、维数、符号和边界项。
  • “进入作者代码复现”：从源码版本和最小示例开始。
  • “这个结果和论文不一样”：比较日志、配置和指标定义。
  • “周复盘”：整理已掌握内容、运行结果和下一步安排。

学习指令在当前对话中使用，不修改课程数据。
