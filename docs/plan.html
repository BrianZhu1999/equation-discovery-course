76篇物理规律发现：30天课程

这门课的终点是：能读懂并推导76篇论文的核心方法；对每篇有公开作者代码的论文，独立复现至少一个支撑核心结论的实验；能用共同数据、假设和验证标准比较不同方法。

原综述保持原样。课程编号 P01–P76 沿用综述，学习顺序重新按先修安排，绝不把“编号靠前”当成“先学”。20篇锚点用于深入推导，其余56篇仍有针对性阅读、自测和复现任务，不豁免有代码的任何论文。

开始学习

打开课程首页，从第 1 天进入论文卡片。使用顶部的导出 / 导入记录按钮备份和迁移进度。

时间是怎样估算的

默认每天6小时，可以改。按20篇锚点各2小时、其余56篇各0.8小时，阅读/推导首次学习约84.8小时；另留16小时周复盘。这是设计估计，复杂推导可能超时，不能据此宣称已掌握。

复现另行计算：每篇普通代码预计2–8小时主动工作，老环境、实验数据或生成式方法预计5–16小时；GPU等待时间不混入主动工作时间。这些区间是排期假设，并未逐个运行测量。

因此“76篇全部读完”和“每篇公开代码均达到论文结果复现”不是相同工作量。在6小时/天预算下，全部作者代码的T2可能超出一个月。面板按当前已定位代码数量显示总量区间；每周用实际耗时重估。有明确截止日期时，可增加每日投入或提前准备环境和批量运行，不能将T1冒充T2。未定位代码也始终保留后续核查任务。

每天的循环

  1. 15分钟主动回忆：不看笔记解释昨天一个公式；处理到期复习题。
  2. 论文阅读与推导：锚点约120分钟/篇，专题约45–60分钟/篇。按问题→主图→方法→验证→限制阅读，不先抄摘要。
  3. 代码工作块：先冻结原文配置、源码版本和目标，再跑最小示例，再跑原文核心案例。每天至少留90分钟；超过预算则移到下一天队列。
  4. 15分钟复述：说明自己真正掌握了什么，尚缺哪份证据；保存答案和阻塞。

一次只排一个主要调试任务。独立GPU作业可以并行，但环境维护、结果核对和公式推导不能无限并行。多张 GPU 可用于独立复现作业；没有并行实现的原作者代码不强行改为多卡。

交互组件

  • 今日课程：每天固定论文、先修按钮、具体推导、单因素改动。
  • 论文地图：标题/作者/关键词/P编号搜索、主题和完成状态筛选。
  • 逐篇自测：301题，先作答后展开核对要点，支持笔记与答案保存。
  • 间隔复习：按自评安排1/3/7/14/30天复习，遗忘则次日重来。
  • 复现实验室：全部论文的作者代码或待核查队列、源码/入口/环境信息、证据登记。
  • 第一课：已经实跑的Lorenz教学脚本，展示候选漏项怎样破坏结构恢复。
  • 对话教练：每篇可复制带学指令，在当前对话中逐题诊断、解释公式、检查实验。面板没有假装接入一个未配置的自动AI评分器。
  • 备份：导出 / 导入学习记录 JSON；浏览器保留上一次保存记录。

完成的定义

阅读完成：不用原文能解释目标、假设、核心转化和至少两个限制；完成本篇推导；四题原则上至少答对三题，错题进入补课。评分为自评或对话教练复核。

作者代码T2：作者代码关系确认、commit与环境可追溯，数据划分及核心案例配置与原文一致，预登记指标与实际结果比较，留下命令、日志和输出。示例启动只算T1。随机算法至少报告多个种子；只跑一个种子时明确标为单次结果。

无代码论文：继续查作者主页/附录/归档，仍无公开材料则记录证据；完成独立最小实现或理论检验，单列为教学替代，绝不算作者代码复现。综述文章P33通过方法谱系比较和批判性阅读验收，不强迫伪造一个“论文程序”。

课程答辩：76篇学习记录齐全；所有确认公开代码的论文达到T2，或逐项保留未解决阻塞，阻塞不计完成；比较矩阵完整；能提出一个有数学依据、对照方法和失败标准的新问题。
